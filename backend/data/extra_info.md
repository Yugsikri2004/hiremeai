## Hardest / Favourite Project (STAR story)
Project: automated value-comparison script for a data migration (GoKloud Software Solutions, deputed at 73 Strings).
- Situation: the team was migrating data from one platform to another in a production fintech application.
  Every value had to match on both platforms, and checking this manually was slow and error-prone.
- Task: Yug had to make sure the data was the same on both platforms after the migration (data parity).
- Action: he stayed calm and focused, and broke the big problem into smaller parts — understand the data
  on each platform, compare values field by field, then report the mismatches. He built and tested each
  part step by step and then combined them into one automated value-comparison script.
  Tool: Selenium. The data was in a "track record" table whose number of rows kept changing,
  so the script had to work for any number of rows instead of a fixed count — this was the tricky part.
- Result: the script validated data parity across platforms and reduced manual effort by 70%.
- What he learned: a big, scary task becomes manageable when you stay calm, split it into small steps
  and finish them one by one. He still uses this approach for every complex task.
